# Handoff: Liquid Glass — светлая (3b) и тёмная (3d) темы + живой фон

## Overview
Тема оформления для мобильного приложения 1M.AGENCY. Одна система в двух режимах:
**3b — светлое стекло** (день) и **3d — тёмное стекло** (ночь). Панели интерфейса —
матовое стекло (`backdrop-filter`) поверх слоя мягких цветовых пятен; пятна медленно
двигаются, поэтому фон живой, но не отвлекает.

Задачи, которые решает этот бандл:
1. **Переключение тем** — light / dark / follow-system, с сохранением выбора.
2. **Живой фон** — анимация, которая не «режет глаз»: длинные периоды, малые сдвиги,
   без смены цвета и яркости, с уважением к `prefers-reduced-motion`.
3. **Единые токены** — вся вёрстка экранов остаётся общей, меняются только переменные.

## About the Design Files
Файлы в бандле — **дизайн-референсы, сделанные в HTML/CSS**, а не продакшн-код.
- `1M Agency Glass.dc.html` — рабочий прототип: экран «Главная» в рамке телефона,
  переключатель темы в шапке, кнопка паузы фона. Открыть в браузере (нужен рядом `support.js`).
- `glass-theme.css` — **это можно переносить почти как есть**: токены обеих тем,
  рецепт стеклянной панели, фолбэк без `backdrop-filter`, keyframes фона.

Задача — воспроизвести тему в существующем окружении приложения (React Native / Flutter /
SwiftUI / Kotlin / web) по принятым в кодовой базе паттернам. Если окружения ещё нет —
выбрать стек и реализовать там.

## Fidelity
**High-fidelity.** Цвета, прозрачности, радиусы, блюры, длительности анимации — финальные.
Данные на экране (клиенты, дела) — демо.

## Как устроена тема

Корневой элемент приложения несёт атрибут `data-theme="light" | "dark"`.
Все компоненты используют только CSS-переменные — ни одного захардкоженного цвета
интерфейса. Исключение: **цвета клиентов** (метки, точки, бары) одинаковы в обеих темах,
иначе теряется узнавание.

Слои экрана снизу вверх:
1. `--bg` — плотная подложка (`#EEF0F4` / `#08090B`).
2. **Слой пятен** — `position:absolute; inset:0; overflow:hidden; pointer-events:none`, три
   размытых круга.
3. **Контент** — `position:relative; z-index:1`, все панели стеклянные.

### Рецепт стеклянной панели

```css
background: var(--glass);
border: 1px solid var(--line);
box-shadow: var(--shadow);
backdrop-filter: blur(28px) saturate(180%);
-webkit-backdrop-filter: blur(28px) saturate(180%);
border-radius: 26px;
```
Блюр по уровням: крупная карточка **28px**, вторичная карточка и таб-бар **24–26px**,
мелкие элементы (аватар, кнопка темы) **20px**. `saturate(180%)` в светлой теме и
`160–180%` в тёмной — именно она даёт «дорогой» вид, без неё стекло выглядит грязным.

Правила, которые легко нарушить:
- **Не больше двух слоёв стекла друг над другом.** Вложенная строка внутри панели —
  не стекло, а `--glass-2` + `--line-2` **без** `backdrop-filter` (иначе двойной блюр и тормоза).
- **Текст всегда полной непрозрачности** — приглушение только через готовые `--ink-2/3`,
  никаких `opacity` на текстовых блоках.
- Контраст в светлой теме проверяется по **самому светлому пятну** под панелью, а не по `--bg`.
- Радиусы: 26 (главная карточка) · 22 (карточка «требуют внимания») · 24 (таб-бар, верхние углы)
  · 16 (строка внутри панели) · 14 (кнопка) · 12 (аватар, кнопка темы) · 7 (чекбокс) · 3 (метка клиента).

### Фолбэк без `backdrop-filter`
Старые Android WebView, часть RN-окружений без blur-библиотеки:
подменяем стекло плотным фоном — light `rgba(255,255,255,.86)`, dark `rgba(24,26,30,.92)`,
пятна остаются (они под панелью, блюр им дают собственный `filter`). Готовый `@supports`-блок
есть в `glass-theme.css`. В React Native: `expo-blur` / `@react-native-community/blur`, а на
Android при `blurAmount` без поддержки — тот же плотный фон.

## Живой фон (главное требование)

Три круга, каждый со своей траекторией, длительностью и фазой. Параметры подобраны так,
чтобы движение читалось периферийным зрением и не мешало тексту:

| Пятно | Размер | Позиция | Цвет light / dark | Период | Траектория |
|---|---|---|---|---|---|
| 1 | 320×320 | `left:-70px; top:-40px` | `#D6F53E` / `#D6F53E` | 22 s | 3 точки, до `+64px, +86px`, scale 1 → 1.14 |
| 2 | 300×300 | `right:-90px; top:190px` | `#7FB0FF` / `#7B4EE8` | 28 s | 3 точки, до `-78px, +58px`, scale 1.08 → 1.00 |
| 3 | 280×280 | `left:-40px; bottom:-60px` | `#FFB07F` / `#F2622E` | 19 s | 3 точки, до `+104px, -52px`, scale 1 → 1.10 |

Общее: `filter: blur(72px)` (light) / `blur(84px)` (dark), `opacity .50` / `.30`,
`ease-in-out`, `infinite`, замкнутая траектория через кейфреймы 0/33/66/100% (не `alternate` —
маятник читается глазом как дёрганье), `will-change: transform`.

**Почему не режет глаз** — это и есть спецификация, не отступайте от неё:
- периоды 19/22/28 с и разные траектории — рисунок фона не повторяется заметно;
- анимируется **только `transform`** (композитный слой, 60fps, без перерисовки);
- сдвиг до 60–100px при размере пятна 280–320px и блюре 72–84px: движение видно,
  но из-за блюра меняется только градиент, резких границ в кадре нет;
- **яркость, цвет и `opacity` не анимируются** — никакого мерцания;
- в тёмной теме прозрачность вдвое ниже и блюр больше: на чёрном любое пятно кажется ярче.

Обязательно:
- `prefers-reduced-motion: reduce` → `animation: none` (в CSS уже есть);
- пауза анимации, когда экран не виден: `document.visibilityState`/`AppState` →
  `animation-play-state: paused` (web) или остановка драйвера анимации (native);
- на списках и при скролле фон не анимируется поверх — он под контентом, `pointer-events: none`.

В React Native эквивалент: три `Animated.View` с `useNativeDriver: true`,
`Animated.loop(Animated.sequence([...три timing по ~7000ms]))`, круг = `View`
с `borderRadius: 160` внутри `<BlurView>`-подложки либо `react-native-svg` +
`<feGaussianBlur>`; на слабых устройствах допустимо заменить анимацию статичным градиентом.

## Переключение тем

Три состояния настройки: `light` · `dark` · `system` (по умолчанию **system**).

```
themeSetting: 'light' | 'dark' | 'system'   // персистится
resolvedTheme: 'light' | 'dark'             // то, что реально отрисовано
```

- при старте: читаем сохранённое значение (`localStorage` / `AsyncStorage` / `UserDefaults`);
  если `system` — берём `prefers-color-scheme` / `Appearance.getColorScheme()` и **подписываемся**
  на изменения (тема должна меняться на лету, без перезапуска);
- переключатель живёт в двух местах: **иконка-кнопка в шапке** (мгновенный тумблер
  свет↔ночь, min-height 34px, стеклянная, подпись моно 10px `СВЕТ`/`НОЧЬ`) и
  **строка в Профиль → Настройки** (`Тема` → `Светлая / Тёмная / Как в системе`);
- смена темы: кросс-фейд **220ms ease** по `background-color`/`border-color`/`color`
  (готово в CSS). Никакого мигания белым: сначала ставим атрибут, фейд делают transition'ы;
- статус-бар: `light` → тёмный контент, `dark` → светлый (`StatusBar barStyle`),
  плюс web `<meta name="theme-color">` с `#EEF0F4` / `#08090B`;
- на web добавьте `color-scheme: light dark` на `:root`, чтобы нативные контролы и
  скроллбары не выпадали из темы.

## Экран-референс: «Главная»

(`padding: 10px 18px 0`, `gap: 16px`) → таб-бар 78px (`margin: 0 14px`, радиус 24px сверху,
нижние 14px — safe area; таб-бар **парит**, подложка видна по бокам).

1. **Шапка**: вордмарк `1M.AGENCY` (Oswald 700 15px, letter-spacing .06em; точка — `--accent-text`),
   справа — кнопка темы (стекло, моно 700 10px) и аватар 34×34 radius 12 (стекло, Oswald 700 13px).
2. **Карточка «ДЕЛА НА СЕГОДНЯ»** — стекло, radius 26, padding 18, gap 14:
   строка даты (`ВС · 6 СЕНТЯБРЯ`, моно 500 10px, tracking .14em, `--ink-2`) и
   `ОСТАЛОСЬ 6` (моно 600 10px, `--accent-text`); заголовок Oswald 700 34px/.92 в две строки +
   счётчик Oswald 700 52px/.8; две строки дел (`--glass-2`, radius 16, padding 11/12, gap 11:
   чекбокс 20×20 radius 7 border 1.5px `--ink-3` · заголовок Sans 600 13.5px + мета моно 500 10px
   `--ink-3` · точка клиента 8px); две кнопки в ряд (`+ ПОСТ` — `--accent`/`--accent-ink`;
   `+ СЪЁМКА` — `--solid`/`--solid-ink`), radius 14, моно 700 11px.
3. **«ТРЕБУЮТ ВНИМАНИЯ»** — заголовок секции моно 600 10.5px tracking .14em `--ink-3`;
   стеклянная карточка radius 22, внутри строки клиентов через `border-top: 1px var(--line-2)`:
   метка 9×9 radius 3 (цвет клиента) · имя Sans 600 14px · статус моно 600 9.5px

4. **Таб-бар** — 5 табов, активный: полоска 22×3 radius 2 + подпись `--accent-text`;

## Производительность — чек-лист
- `backdrop-filter` — дорогая операция: **не более 4–5 стеклянных поверхностей на экране**.
- Стекло **не внутри скролла с большим количеством элементов**: в списках стеклянными
  делаем только «шапку» и таб-бар, карточки списка — `--glass-2` плотным фоном.
- Пятна рисуем один раз на экран, а не в каждой карточке.
- Никакого `blur` на элементах, которые двигаются вместе со скроллом.
- Проверить на самом слабом целевом устройстве до раскатки на все экраны.

## Порядок внедрения
1. Завести токены и переключатель (`glass-theme.css` + настройка в Профиле).
2. Раскатать на «Главную» — это самый плотный по слоям экран, на нём видно всё.
3. Замерить производительность и только потом переносить на Контент-план / Съёмки / Таргет /
   Профиль / Карточку клиента (структура этих экранов — в `design_handoff_1m_agency_app/README.md`).
