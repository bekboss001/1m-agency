# Задача для Claude Code

Сверстать **только бургер-меню** для мобильного приложения 1M.AGENCY. Остальное приложение (шапка, экраны, нижний таб-бар) уже существует — не трогать, не переверстывать, не «улучшать».

Референс дизайна: `Навигация 1M.dc.html` (в этом же репо/папке). Интересует блок в конце файла с комментарием `<!-- menu: full screen, no inner scroll -->` и кнопка «МЕНЮ» в шапке. Всё остальное в файле — только контекст, показывающий стиль приложения.

## Что нужно сделать

1. **Кнопка-триггер в шапке** — пилюля: три лаймовые полоски (третья короче), подпись `МЕНЮ` (mono, uppercase, letter-spacing .14em), рядом лаймовый бейдж-счётчик (сколько скрытых разделов имеют непрочитанное). Высота 40px, border-radius 20px, фон `rgba(255,255,255,.07)`, бордер `rgba(255,255,255,.14)`, hover — `rgba(203,243,79,.16)`. Бейдж — **инлайн внутри пилюли**, не абсолютный (иначе перекрывает текст).

2. **Само меню** — полноэкранный слой поверх приложения:
   - Выезжает сверху: `transform: translateY(-100% → 0)`, `transition: transform .34s cubic-bezier(.2,.86,.22,1)`, opacity .22s. В закрытом состоянии `pointer-events:none`.
   - Фон: `linear-gradient(168deg,#242c0d 0%,#1d2130 34%,#2f2545 64%,#2a1214 100%)`.
   - Шапка меню: заголовок «Все разделы» (20px/800) + подпись mono «N разделов · роль: админ», справа пилюля «ЗАКРЫТЬ ✕» (hover краснеет).
   - Под шапкой — чипы ролей (админ / smm / оператор), активный залит лаймом с тёмным текстом.
   - **Разделы — плитками 2 колонки, сгруппированы** в карточки «Работа» / «Аналитика» / «Команда». Карточка: radius 20, `rgba(255,255,255,.055)`, бордер `rgba(255,255,255,.08)`, внутри заголовок группы mono uppercase 9.5px и сетка.
   - Плитка: **фиксированная высота 70px** (`grid-auto-rows:70px`, `align-content:start`, `flex:none` на карточках группы), radius 15, внутри сверху номер `01` mono + счётчик справа, ниже название 14.5px/800. Активный раздел — лаймовый бордер, фон `rgba(203,243,79,.14)`, лаймовый текст.
   - **Критично: внутри меню НЕ должно быть скролла.** Всё должно влезать на один экран при высоте 860px в любой роли. Плитки не растягиваются по высоте — проверить все три роли (админ = 10 разделов, smm, оператор).
   - Низ меню: строка «Тема» с тремя кнопками СВЕТ / НОЧЬ / СИСТЕМА (активная залита лаймом) и строка профиля: лаймовый аватар «S», имя, роль mono, красная кнопка «ВЫЙТИ».

3. **Поведение**: тап по плитке → открывает соответствующий экран и закрывает меню. Состав разделов зависит от роли. 4 основных раздела (Главная, Съёмки, Таргет/Задачи по роли, Профиль) остаются в нижнем таб-баре — в меню они присутствуют, но помечаются активными так же, как остальные.

## Дизайн-токены

- Акцент (лайм): `#cbf34f`, тёмный текст на нём `#14170b`
- Красный (выход/деструктив): `#ec3013`, текст `#ff7159`
- Поверхности: `rgba(255,255,255,.055)` / `.06` / `.07`, бордеры `rgba(255,255,255,.08)` / `.14`
- Шрифты: Archivo (400–900) для UI, JetBrains Mono для всех мелких uppercase-подписей
- Мелкий mono-текст: 9–10px, `font-weight:700`, `letter-spacing:.12–.18em`, `text-transform:uppercase`
- Радиусы: 20–22 карточки, 15 плитки, 20 пилюли, 11 мелкие кнопки

## Ограничения

- Только меню + его триггер. Никаких правок экранов, таб-бара, контент-карточек.
- Хит-таргеты не меньше 44px.
- Тексты на русском, как в референсе.
