# Handoff: профиль сотрудника (вариант 2a) — 1M.AGENCY

Дополнение к основному хендоффу `../design_handoff_1m_agency_app/README.md`. Все токены, шрифты, цвета клиентов, рамка экрана и таб-бар — оттуда, здесь только новый экран.

## Что делаем
Заменяем вкладку «Профиль» (сейчас она про владельца: 15 клиентов, команда, настройки) на **личный кабинет сотрудника**. Смысл: профиль — инструмент, а не витрина. Человек видит свой объём работы, сроки, своих клиентов и может сам поправить безобидные личные данные.

Прототип: `1M Agency App.dc.html`, канвас, вариант **2a** (turn 2 сверху). Реализовывать нужно его.

**Роль, доступы и распределение клиентов сотрудник не меняет** — только владелец. Это важно для модели прав.

## Структура экрана
Рамка та же: статус-бар 46px → скроллящаяся область (`overflow-y:auto`, padding 8px 20px 24px, вертикальный flex, gap 20px) → таб-бар 78px. Активный таб — `ПРОФИЛЬ`.

### 1. Хедер
Вордмарк `1M.AGENCY` слева (Oswald 700 15px, letter-spacing .06em, точка акцентом) + `МОЙ ПРОФИЛЬ` справа (Mono 500 11px, letter-spacing .08em, rgba(255,255,255,.4)).

### 2. Идентификация + редактирование аватара
Строка flex gap 16, align-items center:
- **Аватар** 78×78, radius 26, фон `#22242A`, border 1px rgba(255,255,255,.1), инициалы Oswald 700 28px rgba(255,255,255,.75). Когда фото загружено — `object-fit: cover` в той же форме.
- **Бейдж редактирования**: absolute right -4 bottom -4, 30×30, radius 11, фон акцент `#D6F53E`, `border: 3px solid #0A0A0B` (вырез в фоне), внутри `+` Mono 700 11px цветом `#0A0A0B`. Тап → системный лист «Камера / Галерея / Удалить фото». Кроп — квадратный, клиентский; на сервер уходит один файл ≤2MB (сжимать до 512×512).
- Справа колонка gap 6: имя Oswald 700 28px капсом · роль `SMM-МЕНЕДЖЕР · 6 КЛИЕНТОВ` Mono 500 10.5px letter-spacing .1em rgba(255,255,255,.42) · `В КОМАНДЕ С МАРТА 2025` тем же стилем, но rgba(255,255,255,.28).

### 3. Карточка «МОЯ НЕДЕЛЯ»

- Шапка: `МОЯ НЕДЕЛЯ` Mono 600 10.5px letter-spacing .14em rgba(255,255,255,.4) + справа диапазон `1–7 СЕН` Mono 500 10px rgba(255,255,255,.28).

  - `ПОСТОВ СДАНО` — 18
  - `СЪЁМКИ` — 4
  - `ВОВРЕМЯ` — 94%, **значение акцентом** (единственная акцентная цифра в блоке)
- Столбики по дням недели: высота контейнера 34px, 7 столбиков flex 1, gap 4px, radius 3; фон rgba(255,255,255,.16), **сегодняшний/максимальный — акцент**. Высота в % от максимума.
- Через `border-top 1px rgba(255,255,255,.08)`, padding-top 13 — **загрузка на неделю**: слева `Загрузка на неделю` Sans 600 12.5px + `22 ИЗ 26 ЗАДАЧ · ЕЩЁ ЕСТЬ МЕСТО` Mono 500 10px rgba(255,255,255,.38); справа бар 74×6 radius 3 (трек rgba(255,255,255,.09), заполнение акцент). При >100% — заполнение `#F2622E` и подпись `ПЕРЕГРУЗ`.

### 4. «МОИ КЛИЕНТЫ»
Заголовок секции Mono 600 10.5px letter-spacing .14em + `ВСЕ 6 →` акцентом справа. Карточка `#141416`, border 1px rgba(255,255,255,.07), radius 16; строки через `border-top 1px rgba(255,255,255,.06)`, padding 13px 15px, gap 11:
метка клиента 10×10 radius 3 (цвет клиента) · имя Sans 600 13.5px · бар 62×5 radius 3 · процент Mono 600 11px (min-width 32, выравнивание вправо).
**Цветовое правило то же, что на главной:** <40% готовности плана — бар и процент `#F2622E`, иначе бар акцентный, процент rgba(255,255,255,.7).
Показывать 3 клиента с наименьшим прогрессом, остальные — по `ВСЕ 6 →`. Тап по строке → карточка клиента (существующий экран).

### 5. «ЛИЧНЫЕ ДАННЫЕ» — что сотрудник может менять сам
Карточка `#141416`, radius 16; строки min-height 44px, padding 14px 15px, `border-top 1px rgba(255,255,255,.06)`: подпись Sans 500 13.5px слева, значение справа.
| Поле | Значение справа | Действие |
|---|---|---|
| Фото профиля | `ЗАГРУЗИТЬ` Mono 600 10.5px **акцентом** | тот же лист, что у бейджа на аватаре |
| Имя в приложении | `АИДА →` Mono 500 10.5px rgba(255,255,255,.45) | инлайн-поле, 2–24 символа |
| Телеграм для связи | `@AIDA →` | поле, валидация `@[a-zA-Z0-9_]{4,32}` |
| Рабочие часы | `10:00–19:00 →` | два тайм-пикера; используются для подсказки «вне рабочих часов» при постановке съёмки |

Под карточкой пояснение Sans 400 11px/1.5 rgba(255,255,255,.3): «Роль, доступы и список клиентов меняет только владелец.» Оно снимает половину вопросов в поддержку — не убирать.

Ниже сохраняем существующие пункты `НАСТРОЙКИ` (тема, push, язык) и кнопку выхода из текущего профиля — стили без изменений.

## Данные (эндпоинт вида `GET /me`)
```
profile:   {id, name, role, clientsCount, joinedAt, avatarUrl|null, telegram, workHours:{from,to}}
week:      {rangeLabel, postsDone, shoots, onTimePct, byDay:[7 чисел], tasksDone, tasksTotal}
myClients: [{id, name, color, done, total}]
```
`PATCH /me` принимает только `{name, telegram, workHours, avatar}` — остальное игнорируется на сервере, не только скрывается в UI.

Все метрики — за календарную неделю пользователя, `onTimePct` = сдано до дедлайна / всего сдано. Пустое состояние первой недели: вместо цифр — строка «Первая неделя — статистика появится в воскресенье».

## Чего сознательно НЕТ (не добавлять)
- Рейтинга сотрудников друг против друга и публичных оценок качества — демотивирует.
- Часов онлайн, геолокации, времени в приложении — слежка.
- Статуса доступности («на месте / на съёмке») — убран по решению заказчика.

Статистика показывает **объём и соблюдение сроков** — то, что человек контролирует сам.
