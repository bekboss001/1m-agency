# Handoff: Liquid-glass меню и кнопка «Меню» (1M.AGENCY)

## Overview
Замена нижнего бургер-меню в мобильном приложении. Текущее меню (см. `current-menu-before.png`) открывается плиточным полноэкранным оверлеем, визуально выбивается из приложения и содержит кнопку «Выйти» прямо в навигации. Новый дизайн — стеклянный bottom sheet со списком разделов, поиском, переключателем темы и карточкой профиля; выход перенесён на экран Профиля.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы в формате HTML** (`menu-design-reference.dc.html`). Это прототип, показывающий внешний вид и поведение, а не production-код. Задача — **воссоздать эти экраны в существующей среде вашего кодовой базы** (React Native / SwiftUI / Flutter / web — что используется), по её паттернам и библиотекам. Если среда ещё не выбрана — выбрать подходящий фреймворк и реализовать дизайн в нём. HTML напрямую не переносить.

В файле несколько вариантов, сгруппированных по «turn». **К реализации: 2a (лист) и 2b (кнопка).** Варианты 1a/1b/1c — более ранние, не-стеклянные итерации, оставлены как контекст.

## Fidelity
**High-fidelity.** Цвета, размеры, типографика и отступы — финальные, приведены ниже точными значениями. Воссоздавать попиксельно, но средствами существующей дизайн-системы проекта: если в ней есть токен с той же ролью — использовать токен.

## Interactions & Behavior
- Тап по вкладке «Меню» → лист выезжает снизу, 280–320 мс, ease-out / spring (damping ~0.8); затемнение появляется параллельно.
- Кнопка остаётся видимой и превращается в крест: повторный тап закрывает лист.
- Закрытие также: свайп вниз по листу (порог ~25 % высоты или скорость > 800 pt/с), тап по затемнению, кнопка «ЗАКРЫТЬ», выбор раздела.
- Выбор раздела: лист закрывается, затем навигация (не наоборот — иначе виден рывок).
- Поиск фильтрует список по мере ввода; группы без совпадений скрываются; при пустом результате — строка «Ничего не найдено».
- Тап по карточке профиля → экран Профиля, где и находится «Выйти» (деструктивный стиль + подтверждение).
- Точка-событие на кнопке гаснет после открытия листа.
- Нажатые состояния строк: подложка `rgba(255,255,255,.12)`, `scale(.99)`.

## State Management
- `isMenuOpen: bool` — открыт ли лист (владелец — оболочка навигации, не таб-бар).
- `searchQuery: string` — сбрасывается при закрытии.
- `activeSection: SectionId` — подсветка текущего раздела.
- `sectionBadges: Record<SectionId, {count, kind: 'accent' | 'warning'}>` — счётчики; сумма > 0 включает точку на кнопке.
- `theme: 'light' | 'dark' | 'system'`.
- Данные: список разделов и роль пользователя фильтруют состав (роль «АДМИН» показывает все 11).

## Замечание про стекло
Liquid glass читается только на цветном/светлом фоне. Если реальный экран под листом почти чёрный, эффект будет едва заметен — тогда стоит либо усилить контентный фон главной, либо поднять непрозрачность листа до `rgba(22,26,22,.72)`.
